# Psi - 1.7.10 Backport

![](https://raw.githubusercontent.com/Vazkii/Psi/master/web/img/logo.png)

Magic?? Tech??

Psi is a mod about spell programming, inspired by Mahouka. This is a backport to Minecraft 1.7.10.

Check out the [official website](https://psi.vazkii.net/index.php) for more info about the original mod.

## About This Backport

This is a work-in-progress backport of Psi from modern Minecraft versions to 1.7.10. The project uses the GTNH ExampleMod template for stable build configuration.

## Building

This project uses a Gradle build system. To build:

1. Run `./gradlew setupDecompWorkspace`
2. Run `./gradlew build`

The compiled jar will be in `build/libs/`
